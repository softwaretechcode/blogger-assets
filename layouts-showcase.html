How to add a feed widget in Blogger

Live

Every feed layout on this page is driven by one thing: an HTML/JavaScript gadget whose content is a three-part string. No XML editing, no server code — you add it entirely from the Blogger Layout screen.

The config string

count / label / layout
# syntax — three parts, separated by slashes, NO brackets count / label / layout # examples straight from the shipped template 15/random/grid-text # 15 posts, random window, text-only grid 9/python/col-left # 9 posts from the "python" label 12/mcq/grid-left-small # 3-col: thumb left, text right android tutorial/feat-big # count omitted → forced to 5 recent/hot-posts # the dark strip under the menu
Do not use brackets. You may see [15/random/grid-text] written informally — but the widget splits the string on / and reads part 1 as the count. With brackets the count becomes [15, which produces the request max-results=[15 and the fetch fails. Type it bare: 15/random/grid-text.

Step by step

Blogger → Layout

  1. Open the Layout screen

    Blogger dashboard → Layout in the left sidebar. You'll see the theme's 19 sections laid out in page order — Top Navigation, Header, Main Menu, Hot Posts, Featured Posts 01–03, Main Posts, the sidebars, and the three footer columns.

  2. Find a section that accepts feed widgets

    Only two section classes actually fire the feed code: featured-posts and common-widget. The full map is in the next section. Click Add a Gadget inside one of those.

    If a section shows max widgets reached, remove one of its existing gadgets first, or drag the new one into a different column.

  3. Choose HTML/JavaScript

    From the gadget list pick HTML/JavaScript — not JavaScript, not Image, not Text. The theme reads the widget's plain text content, so it must be this type.

  4. Paste the config string into Content

    Leave Title blank if you don't want a heading — or fill it in to get the "View All" link appended automatically for the layouts that support it.

    In Content, type the bare config string, e.g. 15/random/grid-text.

  5. Save, then view the site

    Click Save on the gadget, then Save on the Layout itself. Reload the blog. In featured-posts sections the widget lazy-loads once it scrolls within 400px of the viewport, so you may need to scroll to see it.

  6. Verify the label exists

    If you see "Error: No Posts Found", the label segment doesn't match any label on your blog. Labels are matched exactly and lowercased automatically — but spaces are fine: 15/interview questions/grid-text is valid.

Quick test. Paste 6/recent/grid-small into a sidebar gadget. If posts appear, your placement is right. If the literal text appears on the page instead, you're in a section without the right class — see the map below.

Adding the orientation card system to the theme

To add

The .ocard system documented earlier is not in the template yet — it's the proposal this showcase exists to specify. Here's the concrete path from this page to a working Blogger widget: add the CSS once, then use plain HTML gadgets anywhere.

Step 1 — Add the CSS once

Theme → Edit HTML

  1. Open the theme editor

    Blogger dashboard → Theme → ⋮ → Edit HTML. Back up first via Backup/Restore.

  2. Find the stylesheet

    Search for style-ui.css or the last </b:skin> closing tag. Paste the .ocard, .ogrid, .olist and related rules there — before the responsive rules, since responsive.css must load last.

  3. Save

    Click Save. If the save fails, your XML is unbalanced — re-check the braces you pasted.

You only do this once. After the CSS is in the theme, every widget below is pure HTML — no further XML edits, no risk to the theme.

Step 3 — Or hand it to theme.js so it's feed-driven

advanced · Edit HTML

If you want cards that update themselves from your posts, extend the dispatcher. The template builds a <ul> with a per-layout class; add a new branch that emits ocard markup instead.

// theme.js — inside the _item if-chain, add a branch: } else if (_isType('card-left')) { _item = '<li class="feat-item item-card"><article class="ocard o-left s-sm h-zoom">' + '<a class="o-media" href="' + _link + '">' + _img[1] + '</a>' + '<div class="o-body"><h3 class="o-title"><a href="' + _link + '">' + _title + '</a></h3>' + _snip + '</div></article></li>' } // and register it so the config string is recognised: var _feedTypes = [..., 'card-left'];
This is a theme edit, not a Layout edit. It changes theme.js, which the template pins to a jsDelivr tag (@v1.0.0). Editing it locally means you must serve your modified copy and repoint the <script src>, or fork the asset. Do not edit the CDN file — you can't.

Widget configuration syntax

Every feed-driven block is configured by a single line of plain text placed in an HTML widget's content. There is no UI — you type the code and theme.js does the rest on page load.

SegmentMeaningExamples
countNumber of posts to fetch (max 25 from the feed). Ignored by feat-big, mega-menu and related, which use fixed counts.15, 9, 3
labelWhich posts to pull. recent = newest overall, random = random start index, or any Blogger label.recent, random, python, interview questions
